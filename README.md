# Node Desk 3.1 — SSH и Tailscale для Debian

## Установка обновления

Закройте приложение и выполните из папки со скачанным пакетом:

```sh
sudo apt install ./node-desk_3.1.0_all.deb
```

В меню приложений: **Node Desk**. Команда запуска: `node-desk`. Старое имя команды `tailscale-exit-ui` остаётся совместимым.
Пакет называется `node-desk`; при установке apt заменяет прежний пакет `tailscale-exit-ui`. Каталог настроек и системные записи паролей сохранены для совместимости. Предыдущий сохранённый SSH-сервер автоматически переносится в новый список вместе со ссылкой на сохранённый пароль. Настройки Tailscale сохраняются.

В верхней панели — переключатель «Серверы / Tailscale» с выделением активного раздела. Переключение с клавиатуры: Ctrl+Tab.

## Серверы

Тёмная тема, список серверов с поиском, названием, описанием и адресом подключения.

- «+ Добавить сервер» открывает карточку с названием, описанием, IP, портом, username и паролем.
- «Сохранить» добавляет или обновляет запись и возвращает к списку.
- «Подключиться» справа в строке открывает отдельный системный терминал и запускает SSH.
- Нажмите на название/описание или «Открыть →», чтобы перейти к редактированию.
- «← Серверы» возвращает к списку. При несохранённых изменениях запрашивается подтверждение.
- Поиск находит серверы по названию, описанию, IP, порту и пользователю. Длинный список прокручивается колесом или полосой справа.
- «Удалить сервер» удаляет запись и связанный пароль после подтверждения.

Описание и название меняются независимо от пароля. У каждой записи собственный идентификатор пароля, включая записи с одинаковыми IP и username.
Пароль хранится только в системном Secret Service (например, GNOME Keyring), отдельно от JSON. После сохранения поле пароля пустое, а подпись показывает, что пароль сохранён. Пустое поле при редактировании оставляет существующий пароль. Для его удаления есть отдельная кнопка. Пароли не передаются в аргументах процессов или переменных окружения: используется SSH_ASKPASS.

Если хранилище заблокировано, оно может запросить разблокировку. Если Secret Service недоступен, приложение покажет ошибку и не станет сохранять пароль в файл. На минимальном Debian установите `gnome-keyring dbus-user-session` и повторно войдите в графический сеанс. SSH без сохранённого пароля может использовать SSH-ключи или запросить пароль при подключении. OTP/2FA требуют отдельного ввода.

При первом подключении нужно подтвердить отпечаток ключа SSH-сервера. Проверка ключа остаётся включённой. После ошибки SSH терминал остаётся открыт до Enter. Статус SSH отображается в терминале; статус на вкладке Tailscale относится только к VPN.

Данные: `~/.config/tailscale-exit-ui/ssh.json` (учитывается XDG_CONFIG_HOME). Файл содержит названия, описания, параметры соединений и ссылки на секреты, но не пароли. Если файл повреждён, приложение сообщает об ошибке и не перезаписывает его.

## Tailscale

Вкладка Tailscale содержит IP exit node, «Сохранить» и одну кнопку «Подключить / Отключить». Корректный IP также запоминается при закрытии окна.

Tailscale должен быть установлен, авторизован и запущен. Exit node должен быть одобрен в сети. Для работы без запроса пароля один раз выполните от своего обычного пользователя:

```sh
sudo tailscale set --operator="$USER"
```

Это даёт пользователю права управления Tailscale, включая остальные настройки. Приложение не выполняет вход и не меняет настройки оператора самостоятельно.

Статус читается через `tailscale status --json` каждые 3 секунды. «Подключён» означает: Tailscale работает, exit node выбран и сообщает Online. Это не отдельная проверка доступа к интернету. Недоступный выбранный узел можно отключить той же кнопкой. Отключение отменяет только exit node, а не весь Tailscale. Закрытие окна не отключает VPN или открытые SSH-сессии.

## Разработка и сборка

Весь проект находится в этой папке; её можно загрузить в новый Git-репозиторий.
Пользовательские настройки, серверы, пароли и SSH-ключи в проект не включены.

Запуск из исходников на Debian:

```sh
sudo apt install python3 python3-tk python3-keyring python3-secretstorage openssh-client xterm
chmod +x ssh_client.py
python3 node-desk.py
```

Тесты из корня проекта:

```sh
python3 -m unittest discover -p 'test_*.py' -v
```

Сборка Debian-пакета без sudo:

```sh
sudo apt install dpkg
python3 scripts/build_deb.py
```

Результат: `dist/node-desk_3.1.0_all.deb`. Версия задаётся в файле `VERSION`.
Метаданные пакета и ярлык приложения находятся в `packaging/`.
Каталоги сборки и личные настройки исключены через `.gitignore`.

Документация: https://tailscale.com/docs/features/exit-nodes и https://tailscale.com/docs/reference/troubleshooting/linux/linux-operator-permission
